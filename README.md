## Overview

Personal Finance Advisor is a web-based financial management application designed to make personal budgeting simple and understandable.

Users can record their income and expenses, organize spending by category, monitor their savings, set financial goals, and use an AI-powered advisor to understand their financial activity.

The application combines a clean dashboard with AI-generated financial insights to help users make more informed budgeting decisions.

---

## Key Features

### 📊 Financial Dashboard
- View total income
- Track total expenses
- Calculate net savings
- View savings rate
- Monitor recent financial activity

### 💳 Transaction Management
- Add income and expenses
- Select transaction categories
- Add descriptions
- View complete transaction history
- Automatically update financial calculations

### 🤖 AI Financial Advisor
- Analyze recorded financial activity
- Summarize income, expenses, and savings
- Identify spending patterns
- Provide personalized budgeting suggestions
- Highlight areas where spending can be improved

### 🎯 Savings Goals
- Create a savings goal
- Set a target amount
- Track current savings
- Calculate goal completion percentage
- Monitor progress visually

### 📈 Spending Analysis
- View spending by category
- Identify major expense categories
- Understand where money is being spent
